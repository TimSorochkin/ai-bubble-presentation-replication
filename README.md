# AI Bubble Bear Case: Minimal Replication Notebook

A short replication notebook accompanying my [LinkedIn post]([LINK_TO_LINKEDIN_POST](https://lnkd.in/p/erBwKfu2)) co-authored with Max MikoLevine, sharing *The Case for an AI Bubble*, a presentation we prepared and delivered at Justin Hott's Columbia Sunday Finance Seminar.

The notebook reproduces two historical analyses from the presentation:

- **EPS surprises (slide 15):** Nvidia's EPS surprises and subsequent two-trading-day returns, including a fitted linear trend and its zero-return crossing.
- **Market comovement (slide 26):** Weekly Nasdaq Composite/Nvidia return ratios and conditional quartiles for weeks with progressively larger Nvidia moves.

**Run:** Install `numpy`, `pandas`, `matplotlib`, and `yfinance`. Open the notebook in Jupyter and run all cells; price downloads require internet access. The sample ends **October 23, 2026**. Existing notebook outputs are retained for convenient viewing.
